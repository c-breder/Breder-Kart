# Fotos do Breder Kart

Coloque aqui uma foto de cada pessoa. O nome do arquivo precisa ser **exatamente** este, com maiúsculas e espaço:

| Pessoa | Arquivo |
|---|---|
| Anne Elise | `Anne Elise.jpg` |
| Alice | `Alice.jpg` |
| Cecília | `Cecília.jpg` |
| Laura | `Laura.jpg` |
| Luiza | `Luiza.jpg` |
| Davi | `Davi.jpg` |
| Sophia | `Sophia.jpg` |
| João Victor | `João Victor.jpg` |
| Julia | `Julia.jpg` |

Também funcionam `.jpeg`, `.png` e `.webp`, em minúsculas ou maiúsculas (ex.: `Davi.PNG`).

- Se a foto não existir, o jogo mostra o desenho em pixel art.
- O GitHub Pages diferencia maiúsculas de minúsculas: `alice.jpg` não funciona, tem que ser `Alice.jpg`.
- Fotos em pé (retrato) ficam melhores na tela inicial, que corta a foto em 124×150.
